Help & Docs

🚀 Getting Started
1) Configure
Set your MySQL + JWT settings in .env (project root).
2) Initialize Database
Run schema.sql to create tables in MySQL.
3) Sign In
Open /login and create an account if needed.
4) Run Scans
Use individual tools for focused scans, or Advanced Scan to run multi-tool scans and save results to the dashboard.
🔐 Notes
Authorization
All tool requests include your JWT via the Authorization: Bearer header. If your token expires, you’ll be redirected to login.
Scan History
Only Advanced Scan results are persisted to MySQL (via /api/scan/unified).
